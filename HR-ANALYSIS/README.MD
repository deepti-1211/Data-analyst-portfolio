# HR Data Analysis

## Project Overview
This project focuses on analyzing HR data using Microsoft Excel to understand employee-related trends and insights.

## Objectives
- Analyze employee data
- Understand workforce trends
- Identify useful HR insights
- Present findings through clear analysis and visualization

## Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset
HR dataset containing employee and workforce-related information.

## Skills Demonstrated
Excel | Data Analysis | Data Visualization | Business Analysis
